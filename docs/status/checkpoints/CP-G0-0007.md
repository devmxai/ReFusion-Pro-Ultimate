# Product-owner direction

Build every contract and feature for all product platforms from the start. While
no Windows device is available, execute the first real application experience on
macOS only without converting the architecture into a macOS-first fork.

# Enforced interpretation

- macOS and Windows remain equal Desktop-v1 source/product lanes.
- iOS and Android remain portable-contract canary lanes until G9 runtime work.
- Common semantics and Studio commands contain no platform conditionals.
- OS/GPU/media/window code exists only behind platform adapters.
- The repository requires both macOS and Windows Core/Studio/Graphics presets.
- A missing device produces `not-run`; macOS evidence cannot pass Windows or G1.
