# Apple hardware-media surface evidence

## Delivered proof

- Portable C++20 contracts describe exact signed PTS/duration, the bounded
  H.264 AVC 8-bit 4:2:0 NV12 video-range SDR Rec.709 profile, typed capability
  states, engine GPU identity/generation and strict path counters.
- Apple capability admission calls the native hardware-decode query for H.264.
- The probe borrows the engine-owned Metal device, allocates a Metal-compatible
  native NV12 surface and binds its luma/chroma planes as Metal textures.
- Both texture devices match the engine adapter ID and generation.
- A suspended GPU makes the media probe fail closed with
  `RFX-MEDIA-GPU-NOT-READY`; it performs no hidden fallback.
- The separately declared Windows media lane returns
  `RFX-MEDIA-WINDOWS-NOT-QUALIFIED` until G1-WP04 runs on real Windows hardware.
