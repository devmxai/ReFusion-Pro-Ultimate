# Apple hardware-media surface evidence

## Delivered proof

- Portable C++20 contracts describe exact signed PTS/duration, the bounded
  H.264 AVC 8-bit 4:2:0 NV12 video-range SDR Rec.709 profile, typed capability
  states, engine GPU identity/generation and strict path counters.
- Apple capability admission calls the native hardware-decode query for H.264.
- The probe borrows the engine-owned Metal device, allocates a Metal-compatible
  native NV12 surface and binds its luma/chroma planes as Metal textures.
- Both texture devices match the engine adapter ID and generation.
- A suspended GPU makes the media probe fail closed with
  `RFX-MEDIA-GPU-NOT-READY`; it performs no hidden fallback.
- The separately declared Windows media lane returns
  `RFX-MEDIA-WINDOWS-NOT-QUALIFIED` until G1-WP04 runs on real Windows hardware.

## B-frame, VFR, long-GOP and invalidation slice

Checkpoint `CP-G1-0008` adds one portable `HardwareVideoDecodeScheduler` and a
repository-owned 16-frame H.264 High/Rec.709 fixture. The fixture records exact
DTS, PTS, duration, source-frame identity and sync status in decode order; it
contains B-frames, two sync-rooted GOPs, one- and 1,999-tick VFR durations and a
non-zero source origin of `90000/30000`.

The scheduler finds the target by presentation time, walks backward in decode
order to the nearest sync sample, submits only that dependency window to the
platform hardware decoder and retains a bounded immutable PTS queue. An
evaluation stamp copied from Core ProjectClock epoch and engine GPU generation
admits publication; a superseding seek or injected device loss drops the queue
with typed diagnostics before presentation. No media or UI clock is introduced.

On `MAC-LAB-001`, three hardware-required VideoToolbox sessions submitted and
decoded 19 compressed samples, performed three explicit asynchronous-frame
flushes, issued and released all 19 NV12 surface leases and rejected one stale
epoch plus one stale device generation. A long-GOP seek decoded 11 dependency
samples, observed peak residency 11, retained two target/future surfaces and
evicted nine before publication. Skia then selected and GPU-composited source
frames `[9, 10, 9]` from that bounded queue. Software decode, CPU pixel maps,
CPU conversion/upload, GPU readback, cross-adapter events and unattributed GPU
copies all remained exactly zero.

Verification passed Core 18/18, ASan/UBSan Core 18/18, Media 24/24 and physical
macOS Metal/Skia Visual 38/38. The machine-readable receipt is
`docs/evidence/G1/artifacts/G1-WP03-dependency-seek-verification.json`.

## Claim boundary

This proves bounded all-IDR and B-frame/VFR/long-GOP hardware sessions,
sync-rooted dependency seek, exact PTS selection, bounded GPU queue publication
and epoch/device-generation invalidation on macOS. It does not qualify MP4/MOV
demux, production Timeline Video Layer playback, audio ClockSource/drift,
import, export, Windows, iOS, Android, G1 exit or general product codec support.
