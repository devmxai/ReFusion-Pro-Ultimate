# Typed visual-transform authoring evidence

## Delivered vertical slice

- Portable Core accepts one typed `SetVisualTransformCommand` for a stable
  Layer or LayerGroup target through the existing ProjectAuthority.
- Transform replacement is atomic and covers Position, Anchor, Scale, Rotation
  and Opacity. Invalid values, unknown IDs, stale revisions and unsupported
  pass-through Group opacity retain Last-Known-Good.
- Timeline selection is keyed by the immutable engine snapshot ID. QML holds no
  project object and the Inspector reads all values from StudioBridge snapshot
  projections.
- An accepted UI command activates the same snapshot in Runtime, serializes it
  canonically to Project.rfx, records a journal revision and refreshes Timeline,
  Inspector and Canvas consumers.
- An RFX1 source edited through the UI is persisted canonically as experimental
  RFX2 while preserving its project/layer IDs and accepted revision.

Skia or platform type. Studio projection is a Qt adapter. macOS build/test
evidence passes; Windows/iOS/Android runtime remains not-run.
