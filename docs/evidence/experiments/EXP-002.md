# LayerGroup hierarchy experiment evidence

## Delivered vertical slice

- Portable Core now distinguishes `LayerId`, `LayerGroupId` and typed
  `VisualNodeRef`; a Composition persists independent Layer/Group declarations
  plus explicit ordered root references.
- Validation rejects blank/duplicate/global ID collisions, unknown references,
  multiple parents, orphan nodes, child ranges outside their Group, hierarchy
  cycles and unsupported group opacity before activation.
- `Transform2D` adds Composition-pixel anchor. Core evaluates local matrices as
  `T(position) * R(rotation) * S(scale) * T(-anchor)`, recursively multiplies
  parent matrices and returns immutable evaluated leaf Layers.
- Skia no longer independently evaluates layer transform animation. The Metal
  adapter consumes the portable Core world matrix and effective opacity; no
  second clock, evaluator, render authority or CPU pixel path was introduced.
- RFX1 remains readable. Canonical experimental serialization emits RFX2 with
  anchors, LayerGroups, ordered child references and explicit root order.
- Pass-through is honest and bounded: group opacity must equal 1.0 and cannot be
  animated until isolated offscreen compositing is designed and admitted.
- Timeline derives root/child rows from Core hierarchy. The reference project
  shows `Hero Motion Group` plus `Background` at root, rather than seven flat
  rows; double-click navigation exposes the six stable child Layers and the
  breadcrumb/back action changes view scope only.
- CLI `validate` reports Layer/Group/root counts. `describe` reports Group range,
  transform, anchor, animations, ordered child references and root order.
- Newly created workspaces emit RFX2, a matching experimental lock, RFX2 grammar
  guidance and explicit unsupported-capability boundaries.

## Semantic and failure tests

- Parent animation at frame 450 changes the child world translation exactly
  while preserving the child Layer ID and drawing order.
- Grouped serialize/parse/serialize preserves the complete project model.
- Unknown child and non-isolated group opacity return stable
  `RFX-PROJECT-123` and `RFX-PROJECT-121` diagnostics.
- A two-Group cycle returns `RFX-PROJECT-127` before evaluation/rendering.
- Studio integration proves one collapsed Group row, child count, drill-down,
  breadcrumb, live rename/range replacement while focused, and navigation up.
- The shared Skia fixture now contains an animated parent Group, so Metal render,
  presenter and decoded-surface tests exercise the Core hierarchy evaluator.

## Cross-platform state

The model, grammar, validation, transform evaluation, CLI and Timeline contract
are portable C++/Qt boundary code with no platform conditional. macOS has build,
test and physical visual evidence. Windows shared lanes remain defined but were
not run because no Windows device is available; EXP-002 makes no Windows, iOS,
Android or cross-platform exit claim.

## Claim boundary and owner evaluation

This is a bounded hierarchy proof, not G2 completion or professional Group
compositing. There is no group mask, isolated opacity, Group FX, Precomp,
general registry, Undo/Redo, Image layer, video/audio clip or export evidence.

The 2026-08-08 Reels owner review observed a seven-child Subscribe LayerGroup as
one collapsed row, confirming the bounded Group projection. It also found that
a composite Background remained independent root Layers because no typed
Agent GroupNodes/reparent workflow enforces that intent. The mechanism evidence
passes; general topology authoring is partial and is routed through EV-VA-0001
and EXP-006 before RFC-0002 disposition.
