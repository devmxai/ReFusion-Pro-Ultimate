# Semantic authoring and measurement experiment evidence

## EXP-006A delivered slice

- Added Core typed intents for atomic sibling grouping, reparenting and one
  owner-local effect insertion with normal command envelope, CAS revision,
  idempotency and Last-Known-Good behavior.
- Grouping preserves the accepted sibling stacking order even when selection
  order differs. Reparenting validates reachability, one source parent,
  insertion bounds, target range and hierarchy cycles before publication.
- `AddEffect` changes only the target Layer's ordered FX stack and checks the
  complete Layer/Group/root topology before acceptance.
- Added typed unavailable AlignNodes and effect-property animation commands.
  They return stable capability codes and never mutate the accepted revision.
- Added a Core capability snapshot and advisory semantic lint. Lint detects the
  two owner-review patterns without becoming schema validation or revision
  authority.
- Application Host exposes every new intent through the same command service.
- Newly created project-local Skills include semantic ownership/topology rules,
  bounded Background/local-Glow recipes and explicit unsupported-capability
  repair guidance.

## EXP-006B delivered slice

- Added portable TextBox, paragraph layout domains and explicit centered-local
  box/content geometry helpers without serializing any derived glyph metrics.
- Added system versus packaged Font identity. Packaged identity requires stable
  asset ID, family and lowercase sha256 digest; malformed identity rejects with
  `RFX-PROJECT-142`.
- Added strict RFX4 canonical writing and RFX1–RFX3 migration. RFX4 binds the
  running Core visual-property Registry digest and distinguishes Transform
  `position parent_px` from `anchor local_px`.

  `refusion.lock` and the generated project-local Agent property catalog.
- Updated CLI coordinate/Text descriptions and new-workspace RFX4 Skill
  references. Existing external owner workspaces were not modified.
- Added round-trip and negative coverage for TextBox padding, RTL, packaged
  Font identity, Registry mismatch, read-only Font metadata and digest parity.

## EXP-006C delivered slice

- Added the backend-neutral Core `TextLayoutPort`, immutable paragraph result
  and full-descriptor/layout-engine cache key. Derived layout records are not
  present in RFX serialization or mutable Registry properties.
- Core evaluation now emits authored geometry, mask-clipped, effect-expanded
  and world bounds beside an optional shaped Text result at one exact project
  time. Preview and offline probes consume this one evaluated representation.
- Added a Skia HarfBuzz/ICU implementation with cached immutable TextBlobs,
  exact system-family admission and typed fail-closed outcomes for unavailable
  system Fonts and packaged Font assets whose bytes have no admitted resolver.
- Removed the independent Canvas shaping path. The Metal/Skia preview draws
  only the cache entry named by the accepted `TextLayoutResult`; a missing
  result or key rejects the frame with a stable diagnostic.
- Added Skia-enabled `refusion-cli measure`, reporting exact Layer bounds,
  paragraph boxes, line UTF-8 ranges/origins/baselines, metrics, overflow,
  Font digest, layout-engine digest and cache key from the same layout port.
- Added portable and Skia integration coverage for deterministic cache keys,
  exact derived bounds, failure propagation, Latin, Arabic/RTL, mixed direction
  with diacritics, multiline wrapping, clipping, overflow and Font rejection.
  The GPU fixture now contains a real Text Layer, so the shared preview path is
  executed by the physical Metal renderer test.

## EXP-006D delivered slice

- Added one-shot atomic `AlignNodesCommand` execution with explicit geometry,
  logical or ink basis and exact Composition time. It uses the normal command
  envelope, revision CAS, idempotency ledger and Last-Known-Good publication.
- Added one immutable `EvaluatedVisualScene` so hierarchy transforms and Layer
  measurements are created by one accepted-revision traversal rather than two
  independently sampled evaluators.
- Added a portable visual measurement service for authored Shape/TextBox
  geometry, Text logical/ink metrics and active-descendant Group aggregation.
  Derived records remain absent from RFX project truth.
- Alignment operates in Composition/world pixels and inverse-transforms the
  delta through the subject parent. Static Position and animated Position
  curves preserve topology and animation shape.
- Every candidate is remeasured before publication and must satisfy the
  requested anchor relation within `0.25` px. Missing layout ports, invalid
  time/basis, inactive nodes, ancestor relations, singular parents and unstable
  postconditions reject without changing the active revision.
- Application Host routes AlignNodes and the visual Studio composition injects
  the admitted Skia layout port. A canonical RFX round-trip test proves that
  the accepted Transform persists while measurement remains derived.
- Unit coverage includes geometry/logical/ink behavior, nested rotated/scaled
  parents, rotated Group aggregation, multiple requested animation times,
  curve translation, replay, RFX save/reopen and rejection/LKG paths.

The post-implementation EXP-006D receipts are Core 13/13, ASan/UBSan Core
13/13, Studio 18/18 and macOS Metal/Skia Visual 29/29. `docs-doctor` checked 86
documents with zero problems, `architecture-check` checked 67 source files with
