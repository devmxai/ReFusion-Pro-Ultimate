# G0-WP02 evidence

## Completed engineering decisions

- MP-001 and Product Contract activated by explicit user instruction.
- ADR-0001 accepted: C++20 portable baseline.
- ADR-0002 accepted: Qt 6/QML command-only Studio boundary.
- ADR-0003 accepted: Skia GPU 2D/text producer role; backend still a G1 bake-off.
- ADR-0004 accepted: strict hardware video and zero CPU pixel transfer.
- Qt runtime module allowlist and forbidden module policy created.
- Initial narrow OS/media matrix and native codec intake created.
- Noto reference font intake created without downloading unpinned binaries.

## Official facts verified

- Qt 6.11.1 is the current 6.11 patch and standard support is listed through
  2027-03-17; commercial Qt 6.8 LTS updates are listed through 2029-10-08.
- Qt documents commercial and LGPL/GPL lanes, LGPL relinking/source/notice
  obligations, store-conflict risk, and GPL-only modules.
- Windows documents `MF_READWRITE_USE_ONLY_HARDWARE_TRANSFORMS` from Windows 11
  25H2 and fail-closed behavior when a matching hardware MFT is unavailable.
- Apple exposes `VTIsHardwareDecodeSupported`; Android documents Surface output
  as avoiding ByteBuffer mapping/copying.
- Official Noto distribution records its font binaries under SIL OFL 1.1.

## Owner decision resolved

On 2026-08-07 the product owner selected `commercial` in ADR-0005 for the
intended proprietary multi-platform product. The alternative
`lgplv3-compliance` lane was rejected for this release lineage.

This closes the lane decision only. No redistributable Studio artifact is
authorized until vendor entitlement evidence covers the exact release.
