# G1 readiness design evidence

G1 is now split into eight machine-checkable proof packages: macOS presenter,
Windows presenter/Skia bake-off, Apple media surface, Windows media surface,
GPU observability/device loss, packaging/signing, mobile compile canaries, and
the final integrated walking product.

Absolute zero-CPU-video-pixel, software decoder, WARP, fallback, cross-adapter,
unattributed copy and stale-generation thresholds are explicit. The current
Apple M1 lab device is named. Windows device/driver, Qt entitlement and signing
authorities remain external blockers; therefore G0-WP05 and G1 are not passed.
