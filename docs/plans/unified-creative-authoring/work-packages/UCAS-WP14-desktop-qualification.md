# Outcome

Qualify the unified creative-authoring and Agent loop as an installable creator
workflow on macOS and Windows against identical source, assets and contracts.

# Dependencies

Accepted G3 slices, required G4 media/export capabilities and G5 admission.

# Deliverables

- descriptor-driven Inspector, nested Timeline, Recipe browser and Graph Editor;
- visible Receipt ownership/detach/update controls;
- local MCP lifecycle and generated Skill in packaged applications;
- install/create/apply/edit/save/reopen/relink/Undo/Redo/preview/export loop;
- manual and Agent completion of three reference projects, including Editorial
  Paper-Collage;
- calibrated same-commit Metal/D3D semantic, visual and performance comparison;
- installers, update/uninstall, recovery, provenance and support diagnostics.

# Verification and exit

- every included capability satisfies the plan Definition of Done;
- identical project/catalog/package/font/asset/RenderPlan digests are recorded;
- no whole-project rewrite is used for supported local Agent edits;
- p95 authoring and render budgets pass on declared device tiers;
- save/reopen/export and rollback preserve IDs, Receipts and materialized output;
- a new internal installer is emitted for both desktop platforms.

# Failure and rollback

Withdraw individual unqualified packages/tools through the capability ledger or
roll back the complete installer payload. Never patch project meaning per OS.
