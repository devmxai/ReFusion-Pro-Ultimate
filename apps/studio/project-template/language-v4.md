# Project.rfx language v4 — TextBox and coordinate schema

RFX4 preserves the RFX3 hierarchy, paint, masks and owner-local FX. It adds a
registry fingerprint, explicit `parent_px`/`local_px` transform domains, a
centered local TextBox and deterministic Font identity. RFX1–RFX3 remain
readable migration inputs; current canonical saves and new projects emit RFX5.

The `registry digest(...)` value is generated by the engine. Copy it from the
active `Project.rfx` or `refusion.lock`; never invent or change it.

```rfx
rfx 4;
registry digest("rfx-vp-fnv1a64:<engine-generated>");

layer text id("lyr_title") name("Title") {
  range frames(0, 1800);
  transform {
    position parent_px(540, 960);
    anchor local_px(0, 0);
    scale ratio(1, 1);
    rotation degrees(0);
    opacity ratio(1);
  }
  blend(normal);
  content text {
    value("ReFusion");
    font system_family("Arial");
    font_size local_px(72);
    box local_px(900, 140) padding local_px(12, 24, 12, 24);
    direction(ltr);
    horizontal_align(center);
    vertical_align(center);
    wrap(no_wrap);
    overflow(clip);
    line_height ratio(1.2);
    letter_spacing local_px(0);
    fill rgba8("#FFFFFFFF");
  }
}
```

`position` is measured in the immediate parent's pixels; a root node's parent
is the Composition. `anchor` and TextBox geometry are measured in the node's
local pixels. The TextBox is centered at local `(0,0)` before padding. Do not
move `anchor` to compensate for glyph metrics.

For portable qualified output, use one of the immutable Font identities stored
inside this project. Latin and Arabic baselines are created at
`Assets/Fonts/font_noto_sans_regular/font.ttf` and
`Assets/Fonts/font_noto_sans_arabic_regular/font.ttf`.

```rfx
font packaged_asset id("font_noto_sans_regular") family("Noto Sans")
  digest("sha256:f5f552c8c5edb61fe6efb824baf4d4de47b1a8689ab4925ff43f7bd6a4ebece5");

font packaged_asset id("font_noto_sans_arabic_regular")
  family("Noto Sans Arabic")
  digest("sha256:7ed3fe069312aceac454f17cf613a30f95271d6ed7ce58005ed4d016bd3823d7");
```

A system family is a non-qualified authoring convenience. A packaged Font with
missing, escaped or digest-mismatched bytes is rejected before publication and
Last-Known-Good remains active. Do not invent a Font AssetId or digest: read
`Assets/Fonts/catalog.lock`.

Horizontal paragraph alignment supports `start`, `center`, `end`, `left` and
`right`; vertical alignment supports `top`, `center`, `bottom`; wrap supports
`no_wrap`, `word`; overflow supports `clip`, `visible`. Qualified layout uses
the same packaged bytes, Skia/FreeType, HarfBuzz and ICU line-break policy on
all supported backends.
